# Preservation policy

No deletions. Superseded work moves to archive. Aspirational targets such as the 422 FPS design goal remain documented even when not yet achieved. All prior work stays recoverable.

This rule is permanent.

- Do not delete a file to replace it. Move the superseded file into `archive/` with its original filename.
- Add a short note at the top of each moved file stating what replaced it and the date.
- When a living document such as `OPTIMIZATIONS.md` or `EVALUATION.md` is updated, also write an archive copy of the previous content. Do not destroy history by overwriting it with no copy.
- Design targets that are not yet measured, including the 422 FPS goal, stay in the docs next to any newer numbers.
